# Portfolio 2027

Personal portfolio built from the Figma design "Portfolio 2027".

## Run

Static site — no build step. Open `index.html` in a browser, or serve the folder with any static server.

## Structure

- `index.html` — page markup (Home hero, menu overlay)
- `styles.css` — styles; the hero is a 1920×1080 stage positioned with the Figma coordinates
- `main.js` — scales the stage to the viewport, menu toggle, pointer parallax
- `assets/` — SVGs exported from Figma
